# 运维记录模板

状态：当前模板；核对日期：2026-11-16。记录填写实际时间、环境、操作者与结果。
不要填写密码、KEK、Cookie、CSRF、含口令数据库 URL 或私钥。
旧模板见 [归档](archive/cloudflare-2026/README.md)。

## 发布或配置变更

```text
变更编号 / 时间与时区 / 操作者 / 复核者：
环境 / 主机 / 两个域名 / 维护窗口：
目标与影响：
新旧版本、提交、二进制 SHA-256：
工具链版本 / 检查结果 / 实际执行或跳过的测试：
PostgreSQL 版本 / 数据库基线标记：
Nginx、systemd 和非敏感配置差异：
备份编号 / KEK 托管记录编号 / 恢复验证：
本机 live、ready / 外部 HTTPS 验证：
登录、权限、签发、CRL、OCSP、TSA 验收：
错误率、延迟、队列与到期监控：
回滚条件、步骤与数据兼容性：
结果 / 遗留事项 / 负责人：
```

## 备份与恢复演练

```text
时间与时区 / 环境 / 操作者：
备份编号、时间范围、校验和：
数据库和客户端版本 / 分区、函数、权限覆盖情况：
对应 KEK 托管记录编号（不填写密钥）：
隔离目标 / 恢复日志 / 二进制与基线检查结果：
登录、解密、签发、吊销、TSA、审计验收：
恢复耗时 / 可接受数据丢失窗口：
演练库与临时敏感文件清理结果：
问题 / 整改负责人 / 期限：
```

## 故障记录

```text
故障编号 / 开始、发现、缓解、恢复时间与时区：
影响域名、接口、账户范围与持续时间：
版本 / 最近变更：
脱敏 request_id / 错误码 / 日志位置：
数据库、审计分区、队列、NTP、证书到期检查：
根因与证据 / 尚未证实假设：
处置步骤 / 是否影响签发与吊销数据：
恢复验证 / 遗留风险 / 后续行动与负责人：
关联工单与审计记录：
```

操作见 [运维指南](operations-runbook.md)和 [备份与迁移](deployment-migration-export.md)。
记录作为带日期的事实快照保存，不把某次通过结果视为长期结论。
