## 已修正的偏差

| 偏差 | 处理 |
| --- | --- |
| 运维、迁移和业务指南仍以 Pages/Access/Tunnel 为当前部署 | 重写为单体程序、外部 PostgreSQL 和 Nginx，旧内容完整归档 |
| 发布文档声称存在已删除的 GitHub Actions workflow | 当前发布指南说明手工构建、检查与交付，区分原 CFSSL 构建配置 |
| 原需求继续要求 Access 和公开叶证书列表 | 原需求归档，当前范围明确本地认证与公开精确查询 |
| 旧工具链要求、构建状态徽章与当前 fork 混用 | 工具链指向源码声明，说明上游工具文档边界，移除旧徽章 |
| 导出文档把重新输入当前密码写成“新密码” | 明确当前密码、未使用 TOTP、限流和会话期限 |
| 一次性私钥描述遗漏过期及传输失败边界 | 明确 24 小时、服务端擦除时点和无法保证重取 |
| 默认模板范围、CA 导入和恢复保证描述过强 | 明确空 DNS/IP 限制不形成白名单、初始 CRL 可能失败、无历史状态导入接口 |
| TSA 文档遗漏 HTTP 错误，声称恢复后序列号仍受同一约束保护 | 区分 HTTP/DER 状态，说明 Linux 时钟要求与恢复数据分支限制 |
| OpenAPI 缺少工具请求体、部分返回字段及公开存活入口 | 与显式路由和 JSON 字段对齐，补充认证、幂等和错误说明 |
| OpenAPI 把列表证书要求为含指纹、空列表一概定义为数组 | 分开列表与详情模型，对实际会返回 null 的列表建模 |
| OpenAPI 输入/输出模板共用约束，错误限制根默认模板为 397 天 | 分离输入模型与返回模型，保留根 CA 三年模板元数据 |
| DER 使用不适合当前原始二进制传输的 contentEncoding 标记 | 按 OpenAPI 3.1 使用对应媒体类型的原始二进制声明 |
| systemd Documentation 指向部署流程不会安装的本地文件 | 移除不存在的路径，注释指向源码旁的部署说明 |
